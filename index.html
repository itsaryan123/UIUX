Food Safety QA Workflow

Supplier queries should feel trackable, not buried in email.

This concept turns supplier follow-ups into a simple control panel for QA managers: choose a supplier, raise a query with clear labels, and see the response status at a glance.

Primary user
QA manager
Needs a fast way to follow up on food safety information.
Main outcomes
Less chasing, more visibility
Status is visible without opening each query thread.
Interaction style
List → form → status
A short path reduces error and saves time.

User Flow

How the user moves from supplier selection to query submission and then to tracking the response.

3-step flow
1

Select supplier

Browse suppliers with visible status chips and pick the one that needs follow-up.

2

Submit query

Use a short, guided form with subject, category, due date, and a clear question prompt.

3

View status

Track progress on a timeline/card view with readable milestones such as sent, awaiting reply, and resolved.

Short Note

Design decisions focused on speed, clarity, and low cognitive load.

Why these screens

  • The sequence matches the real task order: select supplier, raise the query, then track the response.
  • Status chips and progress bars make query health visible without opening every record.

Why it is simple

  • Forms use short labels, grouped inputs, and one primary action per screen.
  • High contrast text, clear labels, and roomy spacing support readability and accessibility.
