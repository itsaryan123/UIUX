# Supplier Query Module

A responsive UX/UI concept for a food safety QA workflow.

## What is included
- Supplier list page with query status indicators
- Raise new query form layout
- Query status timeline view
- Mobile-friendly responsive layout
- Lightweight interaction for search, filter chips, and submit action

## How to open
- Open `index.html` in a browser.
- The layout is responsive and adapts to mobile widths.

## Project structure
- `index.html` - main UI and content
- `app.js` - lightweight interaction logic
- `README.md` - project notes
